# SutraAI-is-an-AI-powered-personalized-learning-platform
SutraAI is an AI-powered study platform that provides source-cited tutoring, adaptive quizzes, personalized learning, and progress tracking using PDFs, slides, and lecture videos.
SutraAI – AI-Powered Personalized Tutoring & Adaptive Learning

📚 About the Project

SutraAI is an AI-powered learning platform designed to make studying smarter, more personalized, and more reliable. It transforms textbooks, PDF documents, PowerPoint slides, and lecture videos into an intelligent, source-grounded knowledge base.

The platform provides AI tutoring with source citations, adaptive assessments, personalized recommendations, topic-wise mastery tracking, and learning analytics to help students understand concepts and improve their academic performance.

🚀 Key Features

Multimodal Learning: Upload PDFs, PPTs, and lecture videos for automated content extraction.

Source-Grounded AI Tutor: Get answers with citations linked to the original page, slide, or video timestamp.

Adaptive Assessments: Generate MCQs, short-answer questions, and numerical problems based on selected topics.

Answer Verification: Validate generated questions and answers to improve assessment reliability.

Personalized Learning: Track topic-wise mastery and identify knowledge gaps.

Learning Analytics: Visualize assessment performance, progress, and weak topics.

Smart Revision: Receive personalized revision recommendations and study plans.

Topic & Prerequisite Mapping: Explore relationships between concepts and identify topics to learn first.

Knowledge-Based Responses: Flag unsupported questions instead of presenting unverified information as course content.

Performance Evaluation: Measure retrieval quality, answer faithfulness, citation accuracy, and personalization effectiveness.

🧠 How It Works

Upload textbooks, slides, or lecture videos.

Extract text, diagrams, images, and timestamps.

Organize the extracted content into topics, concepts, and prerequisites.

Retrieve relevant evidence to answer student questions.

Generate source-linked quizzes and verify answer keys.

Analyze student responses and update topic mastery.

Recommend personalized practice and revision activities.

Evaluate the system using repeatable tests and measurable metrics.

🛠️ Technology Stack

Frontend: Next.js, React, TypeScript, Tailwind CSS

Backend: Python, FastAPI

Database: PostgreSQL, pgvector

AI: Large Language Models, embeddings, Retrieval-Augmented Generation (RAG)

Document Processing: PyMuPDF, python-pptx, OCR

Video Processing: FFmpeg and speech-to-text transcription

Visualization: Recharts

Testing & Evaluation: pytest, Playwright, RAGAS or an equivalent evaluation framework

Deployment: Docker and configurable cloud services

The final technology stack depends on the integrations implemented in the project.

🎯 Project Objective

The main objective of SutraAI is to build a trustworthy AI learning companion that connects course materials with personalized tutoring. By combining source-grounded answers, adaptive assessments, and learner modeling, the platform aims to make learning more effective, measurable, and accessible.
